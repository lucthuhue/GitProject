# Portfolio Project

Trang web portfolio cá nhân hoàn chỉnh được xây dựng bằng HTML5 và CSS3 hiện đại, chuẩn cấu trúc sẵn sàng để triển khai trực tuyến trên **Netlify Drop**.

## Cấu trúc thư mục:
- `index.html`: File mã nguồn trang web chính.
- `style.css`: File định dạng giao diện chuẩn responsive, typography hiện đại.
- `README.md`: Hướng dẫn sử dụng.

## Cách deploy lên Netlify Drop trong 60 giây:
1. Giải nén file zip này thành thư mục `portfolio-project`.
2. Mở trình duyệt và truy cập: [https://app.netlify.com/drop](https://app.netlify.com/drop)
3. Kéo toàn bộ thư mục vừa giải nén (hoặc các file bên trong) thả vào ô chỉ định của Netlify.
4. Đợi vài giây để nhận địa chỉ website công khai của bạn!
